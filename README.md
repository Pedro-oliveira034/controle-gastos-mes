# Controle de Gastos do Mês

## Descrição

Projeto individual desenvolvido em TypeScript para registrar e consultar despesas, organizar os gastos por categoria e mês e gerar relatórios de despesas.

## Objetivos

* Registrar despesas com suas respectivas informações.
* Consultar despesas por categoria.
* Calcular o total de gastos.
* Identificar a maior despesa.
* Gerar relatórios de gastos por categoria e mês.

## Tecnologias utilizadas

* TypeScript
* Node.js
* Vitest
* tsx

## Instalação

É necessário ter o Node.js e o npm instalados.

Clone o repositório:

```bash
git clone https://github.com/Pedro-oliveira034/controle-gastos-mes.git
```

Entre na pasta do projeto:

```bash
cd controle-gastos-mes
```

Instale as dependências:

```bash
npm install
```

## Como executar

Para executar o programa:

```bash
npm run dev
```

Para executar os testes automatizados:

```bash
npm test
```

Para verificar os tipos do TypeScript:

```bash
npm run typecheck
```
